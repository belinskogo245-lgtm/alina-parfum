# Алина Парфюм

Отдельный магазин партнёра. Основной магазин (`shop`) не изменяется.

- `index.html` — витрина: каталог, поиск, фильтры, корзина, оформление (пока в тестовом режиме — заказы не отправляются).
- `catalog.json` — каталог для витрины. Собирается автоматически каждый час (GitHub Actions → `.github/workflows/catalog.yml`) из публичного каталога поставщика. Содержит только розничные цены в рублях; оптовые цены и курс в файл не попадают.
- `scripts/pricing.mjs` — правила розничной цены (прогрессивная наценка 30/20/15/10%).
- `scripts/build-catalog.mjs` — сборка каталога. Обновить вручную: вкладка Actions → «Обновление каталога» → Run workflow.
- `cabinet.html` — демонстрация кабинетов Алины и поставщика (без настоящей авторизации).
